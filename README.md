# Personal Portfolio

Personal portfolio website built with React and Vite to showcase projects, experience, technologies, and professional background.

## Stack

- React 18
- Vite
- React Router
- CSS Modules / Custom CSS
- React Icons

## Features

The project includes:

- Landing page
- Experience and education
- Certifications
- Featured projects
- Technologies and skills
- Contact and social links
- Downloadable CV

## Design

Modern and responsive interface with a minimal design, smooth animations, and simple navigation.

## Deployment

Deployed with GitHub Pages.
